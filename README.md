# go-scm

공급망·구매·물류·재고·무역통관을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 관세법·대외무역법·FTA관세법·하도급법·물류 관련 법 같은 국내 제도를 뼈대로, 인코텀즈·SCOR·WCO·WTO 같은 국제 기준을 비교하며 배웁니다. 실무를 몇 년째 하고 있지만 체계가 없다고 느끼는 관리자에게도 맞춰져 있습니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만들고, 법령·고시는 튜터가 그때그때 국가법령정보센터·관세청 같은 공식 출처를 열어 확인합니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 시작하는 데 다른 설치는 필요 없습니다. 계산 실습은 평소 쓰는 엑셀·구글 시트로 합니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-scm
```

**Claude Code**

```bash
cd ~/Desktop/go-scm
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-scm` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 지금 어떤 일을 하는지 짧게 묻고, 내 업무에 가까운 영역 몇 개에서 상황 문제를 하나씩 풀어 출발점을 찾습니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답과 내 회사 사례를 반영한 HTML을 만들어 가며 익힙니다. 모듈마다 회사에서 바로 쓸 수 있는 산출물 초안(재고 정책서, 공급사 평가표, 통관·원산지 점검표 등)을 `learner/work/`에 함께 만듭니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 업무 산출물 초안. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 산출물 초안을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 거래처 이름·단가 같은 민감한 정보는 대화에 넣지 마세요. 튜터는 기록에도 그런 값을 「A 공급사」처럼 바꿔 적습니다.

## 알아 둘 것

이 워크스페이스는 교육용입니다. 튜터가 함께 만든 점검표·절차서는 초안이며, 실제 수입신고·품목분류·원산지 판정·하도급 계약 같은 결정 전에는 관세사·변호사나 관세청 사전심사 같은 공식 절차로 확인하세요. 법령은 자주 바뀌므로 튜터가 알려 주는 내용에는 확인한 출처와 날짜가 함께 붙습니다.
